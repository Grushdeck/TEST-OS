# TEST OS - 16-bit Operating System


## Description
TEST OS is a simple 16-bit operating system written in NASM assembly language.

## Commands
- `ls/dir` - show files
- `fetch` - OS information
- `clear` - clear the screen
- `help` - help
- `reboot` - reboot
- `calc` - calculator
- `clock` - digital clock
- `banner` - ASCII art
- and many others!

## Build

### Requirements:
- NASM
- QEMU/DOSBOX (for emulation)

### Build instruction:
- Install nasm (if you don't have it)
- Run build.sh
